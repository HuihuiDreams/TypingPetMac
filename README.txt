================================================================
                    Typing Pet for macOS 使用说明
================================================================

一个专为 Mac 设计的桌面打字陪伴桌宠！
每当你在键盘上打字时，它就会随着你的敲击变换可爱的表情。

> 说明与致谢：
  本项目基于 Jongkeun Choi 制作的开源项目 TypingPetMac 汉化与优化。
  默认桌宠形象为《人渣反派自救系统》的“七九 CP”（岳清源 × 沈清秋），
  素材由画师「-烤得很香的狗蛋-」（LOFTER ID: guduxiaolangnaibu）绘制。
  详情见文末【8. 项目来源、致谢与版权声明】。


【 1. 安装方法（非常重要）】
----------------------------------------------------------------
1. 解压下载的压缩包，得到 TypingPet.app。
2. 务必将 TypingPet.app 拖入「访达」的「应用程序」（Applications）文件夹。
   ※ 注意：不要直接在“下载”文件夹里双击运行，否则后续系统权限可能会失效。


【 2. 首次打开提示“已损坏”或“无法打开”怎么办？】
----------------------------------------------------------------
因为个人分享的软件没有购买苹果昂贵的开发者证书（未签名），macOS 默认会拦截
并提示“已损坏，打不开”或“来自未受信任的开发者”。

这是正常的系统拦截，软件纯本地运行、不联网、完全安全。
只需按以下步骤运行一行命令解除限制：

步骤：
1. 按键盘快捷键 Command + 空格，在聚焦搜索框中输入“终端”并回车打开「终端」。
2. 复制下面这行命令，粘贴进终端窗口，按下回车键（Enter）：

   xattr -cr /Applications/TypingPet.app

3. 再次在“应用程序”中双击打开 TypingPet，即可正常启动！

※ 提示：如果你的应用没有放在应用程序文件夹，可以在终端输入“xattr -cr ”
（注意后面有个空格），然后直接把 TypingPet.app 图标拖进终端窗口，再按回车。


【 3. 开启“输入监听”权限（必做步骤）】
----------------------------------------------------------------
软件需要感知你敲击键盘的时机，才能实时做出表情反应。首次打开必须授权。

授权步骤：
1. 打开应用后，会弹出一个指引小浮窗，点击其中的“打开系统设置”。
   （或者手动打开：屏幕左上角苹果图标  -> 系统设置 -> 隐私与安全性 -> 输入监听）
2. 找到列表中的 TypingPet，将右侧开关开启。
3. 如果列表中没有 TypingPet：
   - 可以直接把指引小浮窗里的猫咪图标拖进系统设置的列表中；
   - 或者点击设置列表下方的“+”号，在“应用程序”中选中 TypingPet.app 添加进来。
4. 开启开关后，指引窗口会自动关闭，宠物立即开始响应打字！

※ 授权后按键没反应排查：
- 方法一：在“输入监听”列表中把 TypingPet 开关关闭再重新打开；或选中按“-”删除后重新打开软件添加。
- 方法二：打开终端输入以下命令回车重置权限，然后重新授权：
   tccutil reset ListenEvent


【 4. 玩法与功能特点 】
----------------------------------------------------------------
- 敲击反应：打字时宠物会随机展示动作，停止打字约 0.75 秒后自动恢复待机发呆状态。
- 拖拽与惯性滑行：按住鼠标可随意移动位置；快速甩动拖拽松手，宠物会带物理惯性滑行一段距离！
- 调整大小与半透明：鼠标移到宠物上方会显示右上角缩放手柄，拖动可放大缩小；鼠标悬停时会自动半透明，不遮挡视线。
- 鼠标避让：在设置中开启“位置锁定下避开鼠标”，光标靠近时宠物会自动溜走躲避。
- 菜单栏爪印：屏幕右上角菜单栏常驻一个 🐾 爪印图标，随时可以点击它打开设置或重新唤出宠物。


【 5. 自定义你的专属宠物 】
----------------------------------------------------------------
点击屏幕右上角菜单栏的 爪印图标 🐾 -> 选择“设置”：
- 更换待机图：选择平时发呆显示的 1 张图片。
- 更换反应图：选择打字时随机切换的图片（支持选多张）。
- 导入图集文件夹：将包含多张图片的文件夹导入为独立图集。
  （命名规则：去掉扩展名后的完整文件名为 idle、pet-idle 或 basic 时可识别为待机图，忽略大小写；多张符合时按文件名排序选第一张）
  （没有匹配的待机图时，按文件名排序的第一张作为待机图，其余作为反应图；只有一张图片时，同时用于待机和反应）
- 特定按键反应：可为回车、空格或快捷键（如 Command+C）绑定专属表情，敲击特定键必定触发。
- 支持格式：PNG、GIF（动图）、JPG、WebP、HEIC 等主流格式。


【 6. 隐私与安全承诺 】
----------------------------------------------------------------
- 绝对安全：软件无任何网络通信代码，纯本地离线运行。
- 不记录文本：仅检测“按键敲击动作”以切换表情，绝不读取、不记录、不保存你的任何输入文字、密码或聊天内容。


【 7. 常见问题 】
----------------------------------------------------------------
Q: 点击宠物上的 × 关闭后，怎么重新打开？
A: 点击屏幕右上角菜单栏的爪印图标 🐾，选择“重新显示宠物”。

Q: 如何设置开机自启动？
A: 点击爪印图标 🐾 -> 设置 -> 通用 -> 勾选“开机自动启动”。

Q: 为什么敲键盘宠物不动？
A: 请确认在「系统设置 -> 隐私与安全性 -> 输入监听」中 TypingPet 的开关已开启。
