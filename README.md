# Typing Pet for macOS

[한국어](README.md) | [English](README.en.md)

키를 누를 때마다 원하는 펫 이미지 중 하나를 보여 주는 네이티브 macOS 메뉴 막대 앱입니다.

<img src="Sources/TypingPet/Resources/pet-idle.png" alt="기본 키보드 고양이" width="180">

Windows용 [swoonqx/TypingPet](https://github.com/swoonqx/TypingPet)에서 아이디어를 얻어 macOS용으로 새로 구현한 비공식 프로젝트입니다. 원본 프로젝트의 소스 코드와 이미지 자산은 포함하지 않습니다.

## 설치

**지원 환경:** Apple Silicon Mac, macOS 13 이상. 현재 공개 버전은 `v0.17.1` 프리릴리스입니다.
Apple이 발급한 Developer ID 인증서로 서명했고 Apple 공증도 통과했습니다. Gatekeeper 경고를 우회할 필요가 없습니다.

### Homebrew로 설치

```sh
brew tap ynifamily3/tap
brew install --cask ynifamily3/tap/typing-pet
```

설치 후 응용 프로그램 폴더에서 `TypingPet.app`을 실행하세요. 기존 앱과 파일이 같으면 `--adopt`로 Homebrew 관리에 등록할 수 있습니다. 다른 버전이라면 기존 앱을 별도로 보관한 뒤 설치하세요.

앱 자체의 자동 업데이트를 지원합니다. Homebrew로 직접 갱신하려면 앱을 종료하고 `brew update` 후 `brew upgrade --cask --greedy ynifamily3/tap/typing-pet`을 사용하세요.

### DMG로 직접 설치

1. [v0.17.1 DMG](https://github.com/ynifamily3/TypingPetMac/releases/download/v0.17.1/TypingPetMac-v0.17.1-arm64-installer.dmg)를 내려받아 두 번 눌러 엽니다.
2. `TypingPet` 앱을 옆의 `Applications` 폴더로 드래그합니다.
3. 디스크 이미지를 추출하고 응용 프로그램 폴더에서 앱을 실행합니다.

DMG도 Developer ID로 서명하고 Apple 공증을 통과했습니다. 같은 릴리스의 `.dmg.sha256` 파일로 무결성을 확인할 수 있습니다.

### ZIP으로 직접 설치

1. [v0.17.1 릴리스](https://github.com/ynifamily3/TypingPetMac/releases/tag/v0.17.1)에서 `TypingPetMac-v0.17.1-arm64.zip`을 내려받습니다. 무결성을 확인하려면 같은 페이지의 `.sha256` 파일도 받습니다.
2. ZIP을 두 번 눌러 압축을 풀고 `TypingPet.app`을 **응용 프로그램(Applications)** 폴더로 옮깁니다. 다운로드 폴더에서 바로 실행하지 마세요.
3. 응용 프로그램 폴더의 `TypingPet.app`을 실행합니다. 메뉴 막대에 발바닥 아이콘이 나타납니다.

두 파일을 함께 받은 경우 다운로드 폴더에서 다음 명령으로 ZIP을 확인할 수 있습니다.

```sh
cd ~/Downloads
shasum -a 256 -c TypingPetMac-v0.17.1-arm64.zip.sha256
```

### 첫 실행: 입력 모니터링

키 입력에 반응하려면 macOS의 **입력 모니터링** 권한이 필요합니다. 첫 실행 안내에서 먼저 키 반응을 체험할 수 있습니다.

1. 체험 영역을 클릭하고 키를 눌러 펫 반응을 확인합니다. 이 체험에는 권한이 필요하지 않습니다.
2. `다른 앱에서도 반응하도록 설정`을 누른 뒤 시스템 설정 > 개인정보 보호 및 보안 > 입력 모니터링에서 `TypingPet` 스위치를 켭니다.
3. 앱이 목록에 없으면 안내의 `목록에 없나요?`를 펼쳐 앱 아이콘을 목록에 드래그합니다. 드래그가 안 되면 `+`로 응용 프로그램 폴더의 앱을 선택합니다.
4. 다른 앱으로 돌아가 타이핑하면 첫 실제 키 입력을 확인한 뒤 안내가 닫힙니다. macOS가 종료 후 다시 열기를 요청하면 안내에 따르세요. 재실행 후 확인 단계가 이어집니다.

`나중에`를 선택해도 앱을 사용할 수 있으며, 메뉴 막대나 설정의 입력 모니터링 항목에서 다시 시작할 수 있습니다.

> [!IMPORTANT]
> 이전 임시 서명(ad-hoc) 버전에서 처음 옮겼는데 반응하지 않는다면, 입력 모니터링 목록에서 기존 `TypingPet`을 `-`로 제거한 뒤 위 순서대로 다시 추가하세요. 이 전환 때는 권한을 한 번 다시 허용해야 할 수 있습니다. 이후 같은 Developer ID 팀으로 서명된 업데이트에서는 권한이 유지됩니다.

**v0.14.1 이하에서 옮길 때는 최신 버전을 한 번 직접 설치해야 합니다.** 이전 업데이트 서명 키를 잃어 새 키로 교체했기 때문에, 이전 빌드는 새 업데이트를 자동으로 설치할 수 없습니다. v0.14.2부터는 앱이 하루에 한 번 새 버전을 확인하고, 사용자가 설치를 승인하면 재시작하거나 종료할 때 적용합니다. [자동 업데이트 문서](developer-notes/updates.md)에 검증 방식이 설명돼 있습니다.

## 동작

- 기본 상태에서는 `pet-idle.png`를 표시합니다.
- 전역 키 입력이 발생하면 활성 이미지 세트의 반응 이미지 중 직전 이미지와 다른 하나를 무작위로 표시합니다.
- 특정 키 또는 `⌃⌥⇧⌘` 조합에 전용 이미지를 지정할 수 있습니다. 정확히 일치하는 규칙이 무작위 반응보다 우선합니다.
- 위치 잠금을 끄면 펫을 직접 드래그해 옮길 수 있습니다. 빠르게 놓으면 속도에 따라 살짝 미끄러진 뒤 부드럽게 멈춥니다.
- 펫에 마우스를 올리면 살짝 커지고, 잡아 끄는 동안에는 눌리는 듯 작아지는 스프링 효과가 적용됩니다.
- 설정에서 상시 투명도와 호버 시 투명도를 각각 조절할 수 있습니다. 기본값은 상시 100%, 호버 시 30%이며 커서 진입·이탈 즉시 적용됩니다. 조작 버튼은 선명하게 유지됩니다.
- `위치 잠금 중 마우스 피하기`를 켜면 클릭 통과 상태의 펫이 가까워지는 커서를 감지해 화면 안에서 부드럽게 자리를 비킵니다.
- 펫에 마우스를 올리면 `×`, 설정 톱니바퀴, 크기 조절 핸들이 나타납니다. 톱니바퀴는 크기 조절 핸들 바로 왼쪽에 있으며 설정 창을 엽니다. `×`는 펫만 숨기며 메뉴 막대의 `펫 다시 표시`로 복원할 수 있습니다.
- 우측 상단 핸들을 드래그하면 이미지 비율을 유지하면서 크기가 바뀌며 설정 창의 크기 값과 동기화됩니다.
- 0.75초 동안 입력이 없으면 idle 이미지로 돌아갑니다.
- 일반 입력 문자는 읽거나 저장하지 않습니다. 키 반응 규칙에는 선택한 물리 키 코드와 보조 키 조합만 로컬에 저장합니다.

## 로컬 개발

개발 빌드는 앱 식별자, 설정, 이미지, 할 일 기록이 분리된 **TypingPet Dev**를 사용합니다. 설치된 배포 앱을 종료하지 않아도 됩니다.

```sh
./scripts/run_dev.sh
```

스크립트가 디버그 앱을 빌드하고 실행합니다. 코드를 바꾼 뒤에는 Dev 앱을 종료하고 다시 실행하세요. 자세한 내용은 [개발 환경과 데이터 분리](developer-notes/development.md)를 참고하세요.

## 할 일과 집중 타이머

펫 근처로 포인터를 옮겨 `할 일`을 선택합니다. 제목을 입력하고 Enter를 누르면 추가됩니다. 각 할 일에는 별도의 카운트다운 또는 카운트업 설정이 있으며, 화살표로 시간을 바꾸고 주 버튼으로 타이머를 시작할 수 있습니다. 집중 화면에서 일시정지, 재개, 종료, 시간 연장이 가능합니다.

할 일과 측정된 집중 시간은 이 Mac의 `~/Library/Application Support/TypingPet/todo-state.json`에 저장됩니다. 설정 > `할 일과 집중` > `기록 데이터 열기`에서 파일을 볼 수 있습니다. 잠자기나 앱 재시작 동안의 시간은 집중 시간에 더하지 않습니다.

자세한 사용법은 [할 일과 집중 타이머 문서](developer-notes/todos.md)를 참고하세요.

## 설정 창

메뉴 막대의 발바닥 아이콘에서 `설정`을 선택합니다.

- `내 이미지 팩`: 팩 선택, 불러오기, 저장·적용, 사용자 팩 목록에서 제거(보조 클릭 메뉴)
- `이미지 프리셋`: 이름을 자유롭게 지정하고 이미지 추가·교체
- `키보드 매핑`: 키와 보조키 조합에 프리셋 지정, 지정 없음·IDLE 설정, 미리보기
- `모양과 동작`: 크기, 투명도, 통통 튀는 정도, 항상 위, 위치 잠금·마우스 피하기
- `할 일과 집중`: 타이머와 기록 데이터 설정
- `일반`: 언어, 화면 모드, 로그인 자동 실행, 입력 모니터링, 업데이트

## 이미지 교체

설정의 `내 이미지 팩`과 `이미지 프리셋`을 사용합니다. 기존 메뉴 막대의 `이미지` 빠른 메뉴도 계속 사용할 수 있습니다.

- `대기 이미지 변경…`: 입력이 없을 때 표시할 이미지 1장을 선택합니다.
- `반응 이미지 교체…`: 키 입력 때 무작위로 표시할 이미지를 여러 장 선택합니다. 개수 제한은 없습니다.
- `이미지 폴더 가져오기…`: 이미지 세트를 갤러리에 추가하고 바로 적용합니다.
- `기본 이미지로 복원`: 앱에 포함된 기본 세트를 다시 활성화합니다. 추가한 갤러리 세트는 유지됩니다.

가져온 세트는 `~/Library/Application Support/TypingPet/Images/Sets`에, 이전 버전의 특정 키 반응 이미지는 `~/Library/Application Support/TypingPet/KeyReactions`에 복사되므로 원본을 이동하거나 삭제해도 계속 사용할 수 있습니다.

### 폴더 세트 규칙

- `idle.*` 또는 `pet-idle.*` 파일이 있으면 대기 이미지로 사용합니다.
- 나머지 지원 이미지는 모두 키 입력용 이미지로 사용합니다.
- 대기 이미지가 없으면 정렬상 첫 이미지를 대기 이미지로 사용합니다.
- 반응 이미지가 한 장뿐이어도 사용할 수 있으며, 폴더에 이미지가 한 장만 있으면 대기/반응에 함께 사용합니다.
- 파일명, 이미지 크기와 가로세로 비율은 자유입니다.
- PNG, APNG, JPG, JPEG, GIF, TIFF, HEIC, HEIF, WebP를 지원합니다.
- 서로 다른 비율의 반응 이미지는 대기 이미지 기준 캔버스 안에 비율을 유지해 표시합니다.

## 빌드

요구 사항: Apple Silicon Mac, macOS 13 이상, Swift 6/Xcode Command Line Tools.

```shell
swift test
./scripts/build_app.sh
open "dist/TypingPet Dev.app"
```

빌드 스크립트는 Keychain에서 `Developer ID Application`, `Apple Development`, 임시 서명 순으로 사용합니다. 특정 인증서를 쓰려면 `CODE_SIGN_IDENTITY` 환경 변수로 지정할 수 있습니다.

공개 배포용 공증에는 Apple Developer Program, `Developer ID Application` 인증서, 키체인에 저장한 공증 자격 증명이 필요합니다. 준비 방법은 [Developer ID 정식 배포 준비](developer-notes/developer-id.md)를 참고하세요.

개발·테스트가 끝나면 [릴리스 자동화](developer-notes/releasing.md)로 테스트 → 빌드 → 서명·공증 → 새 버전 배포를 한 명령으로 실행할 수 있습니다. `version.json`과 변경 내용을 갱신·커밋한 뒤 `./scripts/release.sh --homebrew`를 사용합니다.

```shell
TYPINGPET_BUILD_CHANNEL=production CODE_SIGN_IDENTITY="Developer ID Application: 이름 (TEAMID)" ./scripts/build_app.sh
./scripts/notarize_release.sh
```

처음 실행할 때의 권한 설정은 [입력 모니터링 안내](#첫-실행-입력-모니터링)를 참고하세요.

### 프리셋 팩과 키보드 매핑

설정의 사이드바에서 이미지 프리셋 이름과 이미지를 관리하고, 키와 보조키 조합마다 여러 프리셋을 지정할 수 있습니다. 키보드 위의 **지정 없음**과 **IDLE**도 각각 랜덤 또는 순차 순환으로 설정합니다. 키나 항목을 클릭하면 하나의 아코디언 편집기가 열립니다. **미리보기 모드**로 현재 편집 내용을 시험하고 **팩 저장**으로 적용하세요. 이미지 파일 여러 개 또는 폴더를 불러와 새 팩을 만들 수 있습니다.

구조와 저장 방식은 [프리셋 편집기 문서](developer-notes/preset-editor.md)를 참고하세요.

## 개발 노트

구현과 설계 배경은 [Developer Notes](developer-notes/README.md)에 정리합니다. 현재 동작을 설명하는 안내와 검토 중인 설계를 구분하며, 미구현 기능의 출시 여부·일정·가격은 확정되지 않았습니다.

`docs/`는 Git에서 제외하는 로컬 기획·작업 공간입니다. 공개할 내용은 검토·편집한 뒤 개발 노트로 별도 관리합니다.

## 개인정보 보호

- 일반 입력 문자를 저장하거나 네트워크로 전송하지 않습니다.
- 특정 키 반응에는 사용자가 등록한 물리 키 코드와 보조 키 조합만 로컬에 저장합니다.
- 네트워크 통신은 업데이트 확인과 내려받기뿐입니다. `pet.miel.ing`에 요청할 때 사용자 정보, 기기 식별자, 입력 기록은 보내지 않습니다. 자동 확인은 설정에서 끌 수 있습니다.
- 할 일 JSON 파일에는 제목, 완료 날짜, 타이머 설정, 측정된 집중 시간이 이 Mac에만 저장됩니다.
- 할 일 기록을 서버에 올리지 않으며 계정이나 동기화 기능도 없습니다.
