# 🐾 Typing Pet for macOS

一个专为 Mac 设计的轻量级原生桌面打字陪伴宠物！每当你在键盘上打字时，它就会随着你的敲击变换各种可爱生动的表情，还可以作为你的专注打卡与待办事项助手。

> 📌 **项目说明**：本项目基于原作者 [Jongkeun Choi (@ynifamily3)](https://github.com/ynifamily3) 开发的开源项目 [TypingPetMac](https://github.com/ynifamily3/TypingPetMac) 进行汉化、功能优化与定制。内置默认桌宠素材为《人渣反派自救系统》的 **七九 CP**（岳清源 × 沈清秋），感谢原作者与原画师的贡献！

## 🌟 核心特色与功能

- **⌨️ 敲击反应**：打字时宠物会根据敲击实时切换生动的反应动作，停下打字约 0.75 秒后自动恢复待机发呆状态。
- **📝 待办事项与专注计时气泡**：
  - 点击宠物附近的展开按钮即可调出贴心待办气泡，支持正计时与倒计时专注打卡。
  - 具备 **离开自动暂停检测**（息屏、锁屏或离开电脑时自动暂停计时，恢复使用后继续）。
  - 支持 **紧凑视图** 与 **活动任务视图**，方便查看当前专注进度与历史记录。
- **🎹 原生键盘预设与键位映射编辑器**：
  - 支持在设置的“图集管理”中直观为全尺寸键盘上的每个按键及修饰键（`⌘`、`⌥`、`⌃`、`⇧`）绑定指定表情。
  - 可配置“打字中”与“发呆中”的轮播模式（随机播放或按顺序切换）。
- **🖐️ 自由拖拽与物理滑行**：鼠标按住宠物可以直接挪动位置；如果你快速拖拽后松手，宠物还会带着物理弹性惯性在屏幕上“滑行”一段距离后自然停下！
- **🔍 自由缩放与智能半透明**：
  - 鼠标悬停在宠物上方时会显示控制手柄，拖动右上角把柄可任意缩放尺寸；
  - 鼠标悬停时可自动淡化为半透明（透明度可在设置中自由调节），绝不遮挡正在查看的代码或网页内容；
  - 悬停浮层自带快速齿轮设置按钮和关闭按钮。
- **💨 鼠标靠近躲避**：在设置中开启“位置锁定下避开鼠标”，当鼠标光标移近宠物时，宠物会在屏幕可见区域内灵巧躲闪溜走。
- **⚙️ 菜单栏图标**：屏幕右上角菜单栏常驻 **🐾 爪印图标**，随时可点击唤出待办清单、打开设置、隐藏/重显宠物、切换锁定或检查状态。
- **🛡️ 100% 本地离线运行与隐私承诺**：
  - 不包含任何第三方追踪插件或遥测代码；
  - 仅监听系统底层物理按键敲击信号，**绝不记录、不读取、不上传**任何具体的输入文字或密码隐私；
  - 待办数据与图集配置均保存在本机本地 JSON 文件中。

## 📥 安装与运行

**系统要求**：macOS 13.0 (Ventura) 或更高版本，原生支持 Apple Silicon (M1/M2/M3/M4) 与 Intel 架构 Mac。

### 方式一：下载构建好的应用安装包

1. 前往本仓库的 [Releases 页面](https://github.com/HuihuiDreams/TypingPetMac/releases) 下载最新版的发布包。
2. 解压后将 **`TypingPet.app`** 拖移到访达的 **「应用程序」（Applications）** 文件夹。
3. 双击打开应用即可开始体验！

> 💡 **提示**：如果双击打开时出现系统提示 *“无法打开，因为来自未受信任的开发者”* 或 *“已损坏，打不开”*（这是个人未签名开源软件触发的 macOS Gatekeeper 保护机制）：
> 打开 Mac 的 **「终端」**（Terminal），输入以下命令并回车即可解除拦截：
> ```bash
> xattr -cr /Applications/TypingPet.app
> ```

### 方式二：从源码本地构建（推荐开发者使用）

本机编译的应用享有本地信任证书，无需解除 Gatekeeper 标记：

```bash
# 1. 克隆代码库
git clone https://github.com/HuihuiDreams/TypingPetMac.git
cd TypingPetMac

# 2. 运行单元测试
swift test

# 3. 执行自动化打包脚本
./scripts/build_app.sh

# 4. 打开打包完成的应用
open "dist/TypingPet.app"
```

## 🔐 首次打开：开启“输入监控”权限

为了感知你键盘按键的敲击动作，首次使用时需要为 TypingPet 授予 macOS **“输入监控”（Input Monitoring）** 权限：

1. 应用启动后会自动弹出贴心的权限引导窗口，窗口内自带 **“按键试玩区”**，无需权限即可点击试按查看宠物反应。
2. 点击引导窗口上的 **“打开系统设置”**，系统会自动跳转至「隐私与安全性 -> 输入监控」。
3. 在列表中找到 **TypingPet** 并将开关开启。
4. **如果列表中未出现 TypingPet**：
   - 可以直接将指引窗口中的应用图标拖进系统设置列表中；
   - 或者点击列表下方的 **`+`** 号，在“应用程序”中选中 `TypingPet.app` 确定添加。
5. 开启授权后，返回任意应用敲击键盘，引导窗口会自动检测成功并关闭，桌宠立即开始陪伴你打字！

### 授权后按键没有反应的解决办法：
- **方案一（重开开关）**：在系统设置「输入监控」列表中将 TypingPet 的开关关闭再重新开启。
- **方案二（终端重置）**：在终端执行重置权限命令后重启应用：
  ```bash
  tccutil reset ListenEvent
  ```

## 🎨 自定义你的专属宠物与图集

点击屏幕右上角菜单栏的 **🐾 爪印图标 -> 设置**：

- **图集管理（Set Management）**：
  - 点击左侧侧边栏下方的 **`+`** 可以新建空图集或从包含图片的文件夹直接导入。
  - 支持导入 PNG、APNG、GIF（动图）、JPG、WebP、HEIC 等主流图片格式。
  - **文件夹命名规则**：文件名（不含扩展名）为 `idle`、`pet-idle` 或 `basic` 的文件会被自动识别为待机发呆图，其余文件会被自动分配为按键反应图。
- **键盘预设与键位绑定（Keyboard Mapping）**：
  - 点击键盘上的任意键位，弹出预设选择浮层，可指定按下该键（如 `Space`、`Enter`、`⌘+C` 等）时触发的特定表情。
- **外观与动作设置**：
  - 自由调节平时的常驻透明度与鼠标移入时的半透明度。
  - 调节宠物击键弹跳的幅度（无抖动、轻柔、适中、欢快）。
  - 支持窗口置顶（常驻最前）与位置锁定（点击穿透）。
- **待办与专注设置**：
  - 设置专注倒计时/正计时时长与默认行为。
  - 点击“显示记录数据”可快速在访达中定位并备份你的待办历史记录。
