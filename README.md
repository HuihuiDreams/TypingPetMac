# 🐾 Typing Pet for macOS

一个专为 Mac 设计的桌面打字陪伴宠物！每当你在键盘上打字时，它就会随着你的敲击变换各种可爱生动的表情。

![键盘宠物预览](Sources/TypingPet/Resources/basic.png)

---

## 📥 1. 下载与安装

1. 下载最新版的安装包并解压得到 **`TypingPet.app`**。
2. **非常重要：** 请务必把 `TypingPet.app` **拖入「访达」的「应用程序」（Applications）文件夹**中运行。（不要直接在“下载”文件夹里打开，否则后续权限可能会失效）。

---

## ⚠️ 2. 首次打开提示“已损坏”或“无法打开”？

因为个人分享的软件没有购买苹果昂贵的开发者证书（未签名），macOS 的安全机制（Gatekeeper）默认会拦截并提示：
> *“TypingPet 已损坏，打不开。您应该将它移到废纸篓”* 或 *“无法打开，因为来自未受信任的开发者”*。

不用担心，这是正常提示，软件绝对安全且不联网。只需执行以下一步解除限制：

### 快捷解决方法（只需复制粘贴一行命令）

1. 在 Mac 上打开 **「终端」**（Terminal）：
   - 按键盘上的快捷键 `Command + 空格`，在搜索框中输入 **终端** 并回车。
2. 复制下面这行命令，粘贴进终端窗口，然后按下 **回车键（Enter）**：

   ```bash
   xattr -cr /Applications/TypingPet.app
   ```

3. 再次在“应用程序”中双击打开 `TypingPet.app`，即可顺利启动！

> 💡 *小提示：如果你没有把软件放到应用程序文件夹，可以输入 `xattr -cr`（注意后面有个空格），然后直接把 `TypingPet.app` 图标从访达拖入终端窗口，再按回车。*

## 🔐 3. 开启“输入监听”权限

Typing Pet 需要感知你敲击键盘的时机，才能实时做出表情反应。首次打开时，需要授予 macOS 的 **输入监听** 权限。

### 授权步骤

1. 打开应用后，会弹出一个贴心的指引浮窗，点击其中的 **“打开系统设置”**。
   *(或者手动前往：Mac屏幕左上角  苹果图标 -> 系统设置 -> 隐私与安全性 -> 输入监听)*
2. 找到列表中的 **TypingPet** 并将右侧的开关 **开启**。
3. **如果列表中没有 TypingPet：**
   - 可以直接将指引小窗口里的猫咪图标拖进系统设置的列表中；
   - 或者点击系统设置列表下方的 **`+`** 号，在“应用程序”中选中 `TypingPet.app` 添加进来并打开开关。
4. 开启开关后，指引窗口会自动关闭，宠物立即开始响应你的打字！

### 遇到授权后按键没反应？

- **方法一（重新开关）：** 在「输入监听」列表中找到 TypingPet，先关掉再重新开启；或者选中它点击下方的 `-` 号删除，然后重新打开软件添加一次。
- **方法二（终端重置权限）：** 打开终端输入以下命令回车，然后重新启动软件授权：

  ```bash
  tccutil reset ListenEvent
  ```

## 🎮 4. 怎么玩？功能与特色

- **⌨️ 敲击反应**：打字时宠物会随机展示反应动作，停下打字约 0.75 秒后自动恢复待机发呆状态。
- **🖐️ 自由拖拽与惯性滑行**：鼠标按住宠物可以直接挪动位置；如果你快速拖拽后松手，宠物还会带着物理惯性在屏幕上“滑行”一段距离！
- **🔍 缩放与半透明**：鼠标移到宠物上方时会显示控制手柄，拖动右上角把柄可调整大小；悬停时会自动变为半透明，不挡视线。
- **💨 鼠标避让**：在设置中开启“位置锁定下避开鼠标”，当鼠标光标靠近时，宠物会在屏幕上自动躲闪溜走。
- **⚙️ 菜单栏图标**：屏幕右上角菜单栏常驻一个 **🐾 爪印图标**，随时可以点击它打开设置、更换表情或重新唤出宠物。

---

## 🎨 5. 自定义你的专属宠物

点击屏幕右上角菜单栏的 **爪印图标 🐾 -> 设置**：

- **更换待机图**：设置平时发呆时显示的 1 张图片。
- **更换反应图**：设置打字时随机切换的图片（支持选多张）。
- **导入图集文件夹**：将一个包含图片的文件夹直接导入为独立图集，支持随时切换不同角色。
  - *命名技巧：文件夹里名字带 `idle` 或 `basic` 的图片会自动作为待机图，其余图片作为打字反应图。*
- **特定按键反应**：可以为特殊按键（如回车键、空格、快捷键 `⌘+C` 等）绑定专属的表情，敲下特定键时必定触发！
- **支持格式**：PNG、GIF（动态图）、JPG、WebP、HEIC 等主流图片格式均支持。

## 🛡️ 隐私与安全承诺

- **绝对隐私安全**：Typing Pet **没有任何网络请求代码**，完全离线运行。
- **不记录任何文本**：应用只监听“按键动作”来触发图片切换，**绝不记录、不读取、不保存**你输入的具体密码、文字或聊天内容。

## ❓ 常见问题

**Q: 点击关闭宠物后，怎么让它回来？**  
A: 点击屏幕右上角菜单栏的爪印图标 🐾，选择 **“重新显示宠物”**。

**Q: 想要开机自动启动？**  
A: 点击爪印图标 🐾 -> **设置** -> 在 **通用** 中勾选 **“开机自动启动”**。

**Q: 为什么按键没有反应？**  
A: 请检查「系统设置 -> 隐私与安全性 -> 输入监听」中 TypingPet 的开关是否处于开启状态。
