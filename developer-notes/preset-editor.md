# 动作包与键盘映射 (Preset Packs and Keyboard Mapping)

设置窗口采用全原生架构：AppKit `NSSplitViewController` 负责窗口标题栏、分栏线与常驻 `NSTableView` 侧边栏；SwiftUI 负责右侧内容区渲染。套组管理为扁平列表，点击套组条目的任意区域（包括名称）即可直接进入该套组的统一配置页，上方展示图片预设画廊，下方直接展示键盘映射，省去冗余的二级子页面或卡片跳转。分栏线支持在 240–320 磅之间拖拽调整侧边栏宽度，扩展了鼠标热区便于抓取。侧边栏延伸至标题栏并禁止折叠（包括窗口调整大小时）。系统原生前进与后退按钮可同时恢复设置页面与当前选中的各个套组；前往新页面将清空前进历史记录，删除的套组也会从历史记录中移除。相邻的标题保留为带 12 磅水平边距的纯文本标签，在历史控制按钮之后与文本之后留有间距，并在内容滚动时常驻窗口工具栏。开关偏好设置在分组行中使用系统原生开关。菜单选择器与分段选择器与开关和操作按钮对齐至相同的内容尾端边缘，底部链接在空间不足时采用纯图标排版。侧边栏支持方向键键盘导航，拖拽套组可直接调整持久化排序。

点击“应用套组”才会真正切换当前桌面宠物；选中或编辑非活跃套组不会触发桌面宠物变更。活跃套组与内置默认套组不可从列表中删除。点击侧边栏顶部的加号按钮会弹出原生气泡，输入唯一名称即可创建非活跃的空套组。气泡在展示前预先测量几何尺寸，保证小箭头精准对齐按钮中心；校验提示信息会自动调整尺寸并重新定位同一气泡。点击“添加图片”打开原生系统文件选择器，首张导入的图片会自动填充输入时与休息时的默认反应；空套组无法直接设为活跃套组。“复制套组”会生成并选中一个带唯一命名的新可编辑套组，将原预设的所有图片物理独立拷贝至新套组专用目录中（包括迁移过来的按键反应图片）。新套组完整保留原有的预设名称、选择项、播放顺序与修饰键映射，且后续对任意一方的编辑完全独立互不影响。

每个动作包均拥有可自由命名的图片预设、支持 Control、Option、Shift 与 Command 任意修饰键组合的物理按键映射，以及独立的默认输入反应（Unassigned）和待机休息反应（IDLE）。每个反应项均支持随机播放或顺序播放。随机模式在存在备选图片时会自动避免连续播放同一张图片；顺序模式则严格按照已排定的顺序循环播放。

默认输入反应与待机休息反应卡片展示在键盘上方（中文对应“输入时”、“休息时”）。点击任意反应卡片、键盘按键或空格/回车快捷按钮，会呼出统一的原生 `NSPopover` 弹出面板。锚点矩形在滚动视口坐标系中根据按键尺寸实时测量，弹出面板的小三角精准指向被点击按键或快捷按钮的边缘，并紧密跟随视口滚动。弹出面板内容在展示前预先测量几何尺寸，关闭自动宿主尺寸广播，内容高度动态变化时显式重新测量并平滑调整位置。Popover 的宿主控制器与按键缩略图解耦，选择预设、自动保存、更改播放模式与调整排序时面板保持稳定打开不闪退。点击外部空白区域或按 Esc 键即可收起面板。修饰键使用复选框，去除了冗余的多选说明。空格与回车共享与物理键盘按键相同的修饰键映射层与配置。摒弃了内联手风琴折叠、繁琐的预览模式、录键等待模式、编辑套组状态条或保存按钮。方向键采用标准的倒 T 字形布局（上键居中，左右键置底对齐）。键盘总宽度保持为 760 磅，在宽内容区下自动水平居中。标准字符按键尺寸为 48×48 磅，行宽自适应仅分配给宽特殊按键；功能键行与半高方向键保留其专属轮廓比例。窄内容区通过横向平滑滚动自适应。已启用映射的按键在鼠标悬停时获得系统强调色的填充与描边，按下时提供更明显的按压物理反馈。设置控件、活跃套组指示器、预设选择项与拖放目标均使用 macOS 系统强调色，而非固定的青色着色；分类图标与语义状态色保留其专属色彩。省略了布局说明与键盘说明底栏。画廊图片编辑在同一个 Popover 宿主中复用独立视图。

所有修改在操作发生时均以原子方式即时持久化保存。对当前活跃动作包的修改会立即热重载至桌面宠物。自定义动作包支持在画廊中自由添加、替换、重命名与删除图片预设。内置套组及其五个预设名称在显示时动态跟随当前应用语言（即使配置保存在其他语言下亦然），这不会覆写已保存的数据或翻译用户创建的名称。内置预设画廊为只读保护：图片增删、替换与重命名在编辑器与数据存储层均被严格拦截；但内置包的按键映射、输入/待机反应选择及播放模式依然允许自由配置。点击“恢复默认预设”可随时重置回系统打包的内置图片。删除预设会自动清理按键映射中对该预设的引用；若某按键映射的所有关联预设均被删除，则回退为通用输入反应。如果尝试删除输入或待机反应中的唯一预设，确认对话框会要求先指定替代预设。活跃动作包中的最后一张图片不可删除；非活跃动作包允许清空。导入的图片文件均独立保留在专属存储路径中。

通用设置中将当前 macOS 的“输入监控权限授予状态”与底层“event tap 事件监听连接状态”独立清晰地展示。窗口可见时及应用重新回到前台时自动刷新。点击“重新检测”仅在系统已授权时重试建立底层事件监听。点击“打开系统设置”呼出图文引导。本界面绝不越权申请多余的辅助功能（Accessibility）权限。

## 持久化与兼容性

动作包配置以原子写入方式保存在当前用户环境的 `Images/packs-v1.json` 中。开发版与生产版数据严格物理隔离。旧版本的图片套组在首次启动时自动无缝升级为动作包。原有的全局按键规则在所有现有动作包中均得以完整继承，并引用已拷贝的物理图片。新建的空动作包不带历史遗留映射。无法解析或来自更高版本的配置文件会安全只读保留，防止编辑器意外覆写损坏。

原始图片套组元数据和旧版按键规则安全留存，数据迁移不会删除用户的任何源文件。桌面宠物、托盘菜单与设置界面共享统一的 `PetPackStore` 与 `PresetPlaybackCursor`。桌面宠物在其他前台应用中响应打字依赖系统“输入监控”权限。

## 本地测试验证

```sh
swift test
SWIFT_BUILD_CONFIGURATION=debug TYPINGPET_BUILD_CHANNEL=development CODE_SIGN_IDENTITY=- ./scripts/build_app.sh dist-dev
open "dist-dev/TypingPet Dev.app" --args --show-settings
```

在重新构建前请务必先退出开发版应用。原生 UI 验证涵盖侧边栏拖拽折叠与导航、单一 Popover 状态保持、多选与顺序调整、修饰键组合、空动作包创建与导入激活、画廊预设删除、复制套组数据独立性以及真实权限状态呈现。自动化测试全面覆盖数据迁移、图片独立隔离、自动保存与重启恢复、非活跃套组编辑、显式激活、删除降级兜底、播放顺序循环、写入合法性校验、损坏文件保护、分栏尺寸限制与权限连接分离等核心逻辑。
