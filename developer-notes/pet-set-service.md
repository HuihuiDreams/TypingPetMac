# 动作包在线服务设计评审 (Pet Set Service Design Review)

撰写 / 修订日期：2026-10-24

当前状态：**设计方案评审 / 暂未实现**

当前版本的 TypingPet 图片套组完全存放在本地，不提供云端账号、兑换码激活、在线支付或素材上传功能。本篇笔记旨在对未来可能引入的在线动作包分发与权益恢复机制进行架构评估。以下关于价格、容量及账号设计的讨论均为早期构想，不构成商业销售承诺。

## 1. 业务架构与构想方向

| 业务维度 | 评估要点 | 候选方案 |
|---|---|---|
| 内置基础动作包 | 特殊保障 | 随 App 内置打包，无须登录或联网即可永久离线使用 |
| 拓展动作包 | 云端统一管理 | 官方扩展包与个人云端素材由服务器统一管理元数据与授权 |
| 动作包获取方式 | 输入标准兑换码 | 兑换激活 → 账号绑定永久权益 → 下载到本地 → 一键启用 |
| 兑换码格式 | `TYPING-PET-XXXX-XXXX` | 字母与数字组合，带校验和防暴力碰撞 |
| 定价与权限体系 | 灵活策略 | 支持免费与付费分流，将销售价格与兑换码逻辑解耦 |
| 自定义扩展权益 | 单次买断 | 考虑单账号单次低成本买断，不按图片张数计费 |
| 验证策略 | 渐进式验证 | 优先使用内部测试码验证兑换、下载与恢复全流程 (POC) |

**核心准则：激活码仅为兑换权益的凭证，激活后使用权限永久绑定至用户账号。** 同一动作包可批量生成多个兑换码；动作包购买与高级自定义功能解锁彼此独立。

## 2. 云端分发与本地运行边界

| 对象 | 原真源与管理归属 | 本地客户端保留项 |
|---|---|---|
| 内置基础包 | App Bundle 本地文件 | 内置物理图片 |
| 官方扩展动作包 | 运营云端服务器 | 本地缓存副本、当前激活与配置状态 |
| 个人云端动作包 | 用户私有云端沙箱 | 本地编辑暂存与离线缓存副本 |
| 授权与激活记录 | 云端主库 | 离线验签后的本地持久化授权凭证 |
| 窗口坐标与偏好设置 | 当前 Mac 本地偏好设置 | 用户视觉与交互偏好 |

- 严禁在客户端安装包中写死全部扩展动作包资源或硬编码兑换码列表，上架新动作包不得依赖发版发包。
- 官方动作包由运营方在后台统一更新版本；客户端不直接覆写官方原件。
- 断网环境下已下载安装的动作包可不受影响继续离线使用。激活新兑换码、初次下载与云端同步需联网连接。
- 个人素材上传提供明确的交互确认，点击“保存到我的账号”后才发起网络请求。

## 3. 用户界面与核心交互流

建议将设置中原有的画廊重构为专属的“宠物动作包”管理台，分为“我的动作包”、“兑换激活”与“新建动作包”三大核心入口。

### 我的动作包
- 以卡片形式清晰展示内置包、已激活的官方扩展包与个人私有动作包。
- 卡片标注：缩略图、名称、作者、`使用中`、`待下载`、`有更新` 等状态标签。
- 详情浮层支持键入预览待机动作与打字反应。
- 点击“从当前 Mac 清理”仅释放本地下载的图片缓存，保留账号对该动作包的拥有权。

### 兑换码激活流程
1. 点击“兑换激活”，粘贴兑换码。
2. 校验通过后自动绑定至当前登录的 Apple/服务账号，并提示立即下载启用。
3. 网络中断或偶发失败时，权益已落库，用户可在“我的动作包”中随时点击“重新下载”。

## 4. 离线使用与数据保护

为保证 TypingPet 轻量、隐私无扰的核心体验：
- 离线验签：客户端缓存包含非对称数字签名的授权凭证（License Token），在断网场景下无需频繁联网验证。
- 零遥测隐私底线：不收集用户击键内容、不追踪应用使用轨迹，仅传输动作包资源与兑换状态。
