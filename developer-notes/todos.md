# 待办事项与专注计时器 (Todo and Focus Timer)

待办事项功能属于可选功能。首次启动时默认仅显示宠物。将鼠标指针悬停在宠物附近，点击出现的 `待办事项` 气泡按钮即可打开。
菜单栏托盘中也提供 `显示待办事项` 选项。

## 添加与管理待办事项

1. 在列表顶部的 `添加待办事项…` 输入框中输入标题。
2. 按回车键（Enter）。新创建的待办事项将直接插入在输入框下方，输入框继续保留焦点，方便连续添加。
   未完成的待办事项按创建时间由新到旧倒序排列。
3. 点击待办事项左侧的圆圈即可标记完成。勾选动画播放后，该条目会移入 `今日已完成` 分组中。

列表会跨日期保留未完成的待办事项。`今日已完成` 仅展示当前本地自然日内完成的项目。
展开该分组后可撤销完成状态。
点击待办标题可直接原地编辑名称。光标将定位在鼠标点击的位置，不会选中文本或触发重排，列表行保持稳定。
每个标题均使用单一 AppKit 输入框（`InlineTitleField`），支持最多显示两行并在末尾截断显示 `…`，支持原地编辑。
按回车保存更改，按 Esc 取消并还原旧标题。
点击其他标题、添加输入框或切换到其他应用也会自动保存。如果内容为空则保留原标题。
行内菜单和右键菜单中也提供 `重命名` 选项。
添加输入框与标题编辑器均为极简设计，不显示边框或下划线。
添加输入框显示淡灰色加号图标，鼠标悬停或有未提交草稿时显示轻微底色。编辑标题时保留底色高亮并显示光标。

### 标题长度规则

| 场景 | 规则说明 |
|---|---|
| 长度限制 | 去除首尾空白后为 1–120 个字符。每个字符、表情符号（Emoji）均计为 1 个字符。 |
| 空白符处理 | 换行符与连续空格（无论是键入还是粘贴）均合并为一个空格。 |
| 输入反馈 | 达到 100 字符后显示 `n/120` 计数器，最多允许输入 120 字符。 |
| 添加输入框 | 随着输入最多展开至 3 行，超出后支持滚动。 |
| 列表条目 | 最多显示 2 行，超出在末尾显示 `…`。鼠标悬停提示工具框展示完整标题。 |
| 编辑状态 | 编辑时最多可展开至 4 行。2 行以内的标题编辑时高度不变，更长标题编辑时自然展开。 |
| 专注气泡、活跃卡片、删除提示 | 单行显示，超出末尾截断显示 `…`。 |
| 切换提示 | 确认弹窗中引用的标题最多截取前 24 个字符。 |
| 历史记录 | 在此规则实施前保存的历史超长标题保留原样，直到下次编辑时再进行规范化。 |

上述规则由 `TodoState.swift` 中的 `TodoTitlePolicy` 实现。

气泡面板中的所有文本输入框均完整支持 ⌘A、⌘C、⌘V、⌘X、⌘Z 与 ⇧⌘Z 快捷键（包括中文/韩文等三方输入法环境）。
由于应用本身不常驻标准主菜单栏，待办气泡面板内部独立路由处理这些快捷键，并通过隐藏的 Edit 菜单为弹出面板和设置窗口提供剪贴板与撤销支持。
开启 macOS 全键盘控制后，Tab 键可聚焦各个待办标题。辅助功能 VoiceOver 提供 `完成`、`开始计时` 与 `删除` 操作。
行内菜单与右键上下文菜单同样支持删除待办。删除时会在条目内直接弹出二次确认。
删除操作会软隐藏该待办并保留其关联的专注计时历史会话。

气泡面板尺寸自适应内容，气泡小尾巴始终指向桌面宠物。
顶部标头展示当前本地日期以及未完成的待办事项总数。

## 气泡尺寸与显示模式

点击顶部标头中的字号按钮（中文/英文环境下为字号图标，韩文系统为 가가）或打开 设置 > `待办事项` > `气泡` 均可调整气泡尺寸。
字号缩放比例参考浏览器阶梯档位：80%、90%、100%、110%、125%、150%、175% 与 200%。文本与所有控件均在各个比例下原生矢量布局重绘，而非位图缩放。
当气泡拥有键盘焦点时，亦可使用快捷键 ⌘+（或 ⌘=）、⌘− 以及 ⌘0 缩放，并在切换时短暂显示尺寸指示角标。

`显示方式` 支持将气泡设为常驻可见（`始终显示`，默认值），或者仅在鼠标悬停时展示（`悬停时显示`）。
在悬停模式下，鼠标移动到宠物上方时气泡浮现；指针在气泡内部操作时保持展示，指针移出后平滑淡出。
`常驻不透明度` 与 `悬停不透明度` 逻辑与宠物本体透明度设置相同，100% 为完全不透明，0% 为完全隐形。
`常驻不透明度` 作用于 `始终显示` 模式下鼠标离开时的透明度；`悬停不透明度` 作用于鼠标悬停在宠物或气泡上方时的透明度。
气泡透明度为 0% 时会忽略鼠标事件实现点击穿透，直到指针再次唤起它。
当用户正在打字输入、弹出层或上下文菜单打开时、倒计时结束提醒时以及发生保存错误时，气泡将强制保持可见且完全不透明。
气泡尺寸与显示偏好保存在应用的 `UserDefaults` 偏好设置中，不混入待办业务数据文件。

### 紧凑精简视图 (Compact view)

如果希望常驻气泡占用更少的屏幕空间，可以点击标头右上角的 ⤡ 按钮，或在 设置 > `待办事项` > `列表视图` 中切换为紧凑精简视图。
精简视图宽度仅为 260 磅，最多展示前 3 条未完成待办（每条一行，带勾选框）。
当前正在计时的待办事项固定置顶，并展示实时倒计时。超出 3 条的项目展示为 `+N 个更多`，点击即可一键展开完整视图。
精简视图隐藏了日期标头：鼠标悬停时，右上角浮现 ⤢（展开完整视图）与 ⌄（折叠回专注浮窗）操作按钮。
右键上下文菜单提供完全相同的操作项。
在精简视图中右键任意待办，可以直接管理该项目的计时器。
对正在计时的待办，右键菜单提供 `暂停` / `继续` 和 `结束`；对其他待办，提供其保存的专注时长、正计时模式或 20 分钟快捷启动。
在已有计时器运行的情况下启动另一项待办，会在精简气泡内部弹出切换确认提示。
从精简视图启动计时器会继续停留在精简视图模式，正在计时的待办及其时间展示在最顶部。
计时结束或检测到离开时需要更多展示区域，此时会自动展示专属弹窗，处理完毕后自动恢复为精简视图。
应用退出并重新打开时，活跃会话与精简视图状态均能保持恢复。
待办的新增、编辑、删除及自定义时长等复杂操作在完整视图中进行。
视图选择持久化存储在显示偏好中。在切换视图模式时会自动保存当前正在编辑的标题。

## 专注计时器功能

每个新待办默认预设 20 分钟专注倒计时。点击右侧主按钮即可直接按预设时长启动计时。
点击箭头下拉菜单可选择 10 分钟、20 分钟、30 分钟预设、自定义时长或正计时模式（Count-up）。
自定义时长支持 1 到 999 之间的任意整数分钟。在下拉菜单中切换选项仅更新预设配置，不会立即启动计时。
每个待办条目各自独立保存专属的计时预设。

从完整视图启动计时后，界面会收拢为紧凑的专注浮窗（Focus view），展示待办标题、番茄图标与时间读数。
番茄图标外围的圆环直观展示倒计时剩余比例；正计时模式由于无时间上限，因此只展示番茄本体。
计时暂停时，番茄图标转为灰色并标注 `暂停`。
鼠标悬停在浮窗上方时，会浮现暂停、继续和结束控制按钮。
点击浮窗主体区域可展开回到完整列表；计时在后台持续精准计算。
展开完整列表时，正在计时的待办将在列表顶部以高亮卡片形式展现，并自带独立控制面板。
点击标头折叠箭头或按 Esc 键即可收回至紧凑专注浮窗。

倒计时到达零点时自动停止。精简到期浮窗提供延长时长与结束计时操作。
气泡会轻快弹跳远离宠物，类似于 macOS 菜单栏或 Dock 图标吸引用户注意力的跳动反馈。
如果倒计时结束时您正处于离开状态，那么在您下次操作键盘或移动鼠标时，气泡会再次跳动提醒。
点击延长按钮右侧箭头可修改追加时长，点击主延长按钮会在同一会话内追加该时长继续计时。
在零点等待用户操作的静止时间不计入专注总时长。结束计时不会自动将该待办标记为已完成。
将正在计时的待办事项勾选为完成时，会自动先结束计时会话并保存，随后归档条目。

当一个计时器正在运行时点击启动另一个待办，会在气泡内弹出切换确认提示。原有计时器保持当前状态，直到您点击 `切换`。
点击取消保留原会话；点击确认将自动结束原会话并无缝开启新会话。

### 离开检测 (Away detection)

当检测到用户离开电脑时，正在运行的计时器会自动挂起暂停：连续 15 分钟无键盘鼠标操作、屏幕锁屏或系统睡眠。
计时器还会自动扣除自最后一次输入以来的空闲时间，避免忘记暂停时将整晚的待机算作专注时长。
空闲检测基于系统底层空闲时钟读取，无需任何多余权限。
检测到离开后，气泡保持展示，说明离开时长并提供三个选项：

| 选项 | 离开时长的处理 | 计时器后续状态 |
| --- | --- | --- |
| `继续计时` (不计入) | 扣除离开时长 | 恢复运行 |
| `计入离开时间` | 计入离开时长，宛如计时从未暂停 | 恢复运行；若为倒计时且超时则直接触发结束 |
| `结束本次计时` | 扣除离开时长 | 立即保存并结束本次会话 |

在用户做出选择之前，计时器保持暂停，并且这段争议时长不会写入数据记录。
列表顶部卡片同步展示该状态并提供相同的选择按钮。
`计入离开时间` 计算基于系统运行时间（Uptime），系统休眠期间时钟冻结，因此绝不会将睡眠时间误算入专注。
在 设置 > `待办事项` > `离开检测` 中，可将判定阈值设为 5、10、15、30、60 分钟，或彻底关闭检测。
关闭后恢复原有机制：仅在系统睡眠时暂停，不扣除空闲时间。
离开提示保存在内存中，重启应用后未确认的会话自动按普通暂停状态处理。

气泡弹跳动画忠实还原了 macOS 原生 Dock 图标跳动的物理曲线，以 48 磅标准 Dock 逐帧逆向标定：
三次抛物线弹跳幅度分别为 53、26 和 13 磅，持续时间分别为 0.50、0.32 和 0.22 秒。
当屏幕边缘空间受限时，会在保持重力加速度不变的前提下自适应调低弹跳高度与周期。
与 Dock 紧急提醒一致，每隔 2 秒重复弹跳一次，直到鼠标移动到气泡或宠物上方，或用户做出选择。
最多重复五轮后停止。若系统开启了“减弱动态效果”，气泡将保持静止不弹跳。

## 窗口层级、隐藏与定位

桌面宠物与待办界面使用两个独立的 AppKit 面板（Panel）。位置锁定后，鼠标点击穿透宠物本体，
但待办气泡面板及其入口按钮依然正常接收鼠标点击。
待办面板依附于宠物旁侧，采用固定大小的透明画布，使气泡内部可以在不改变外部窗口 frame 的情况下平滑进行缩放和弹跳动画。
气泡内部自行绘制投影，投影紧密跟随动画形态，并在窗口获得或失去焦点时保持稳定无闪烁。
点击气泡外的空白区域或气泡隐藏状态下的所有点击均直接穿透传递到下层其他应用窗口。
气泡内的悬停由鼠标绝对坐标与 SwiftUI 动态布局几何计算而来，不依赖 AppKit tracking rects，
因此在编辑长标题或列表滚动时，各行操作按钮响应极其灵敏。
图标按钮、`…` 更多菜单及字号按钮在悬停时展示圆形底色。文本输入框在悬停时即显示 I 型文本光标。
macOS 原生会忽略非前台应用发起的鼠标光标切换，本应用在启动时通过内部 `BackgroundCursor` 机制适配 WindowServer 特性，
在后台即可即时改变悬停光标样式；如未来 macOS 版本变动，则平稳降级为点击面板后再改变光标。
待办面板上的按钮点击无需窗口激活，因此打字输入流绝不会从用户当前前台软件中被窃取。
仅在用户点击 `待办事项` 展开面板、点击文本框、原地重命名或输入自定义分钟数时，面板才会按需获取键盘输入焦点。
待办面板随宠物的移动和缩放自动吸附重合，优先利用宠物上方的可用屏幕空间，上方受阻时自适应切换至侧方或下方。
待办面板保持与宠物相同的窗口层级与全屏 Space 策略。
在操作待办面板或入口按钮时，宠物的光标躲避避让逻辑自动暂停。

点击 `隐藏待办事项` 可以单独隐藏待办界面，后台计时器继续平稳运行。隐藏宠物本体则会同步隐藏待办浮窗。
点击菜单栏中的 `显示待办事项` 即可随时恢复宠物与列表展示。
设置窗口中设有 `待办事项` 专属标签页，提供完整的开关与视觉控制选项。

## 时间计量与本地存储

正式版本地数据持久化文件路径为：

```text
~/Library/Application Support/TypingPet/todo-state.json
```

本地开发调试版本使用独立文件：`~/Library/Application Support/TypingPetDev/todo-state.json`。
关于独立的 bundle identifier 与运行调试命令，请参考 [本地开发](development.md)。

在 设置 > `待办事项` > `打开记录数据` 中，可以在 Finder 中直接定位该数据文件。
数据结构包含 schemaVersion: 1、功能偏好设置、待办列表、专注会话历史以及时长追加片段记录。
所有日期均以 UTC ISO 8601 标准字符串存储，已完成列表按用户本地日历划分。
秒数保留浮点小数，每个会话的总时长严格等于其所有时间片段之和。

计时核心采用单调时钟计算实际逝去时长，不依赖不稳定的定时器回调累加。
倒计时时间片段以设定上限为准，暂停期间和超时等待操作的时间均被排除不计入。
状态发生变更时即时保存，计时运行期间每隔约 5 秒写入一次运行检查点（checkpoint）。
写入采用原子替换文件（atomic write），若文件损坏或版本不兼容将拦截写入以保护原数据。
保存发生异常时会在面板顶部给出警告。在正常退出应用时若保存失败，会提示重试、取消或不保存直接退出。

Mac 睡眠会自动暂停并持久化当前计时，系统唤醒后保持暂停不会自发继续。
正常退出应用会保存暂停状态，意外重启后会自动恢复最近一次检查点并置为暂停。
应用不会补充离线时间。若遇偶发断电崩溃，最多仅损失自上次成功检查点（约 5 秒内）的数据。
备份时直接复制该 JSON 文件即可。还原或手动编辑前请务必先退出 TypingPet。
应用 100% 离线，无云端账户、无同步服务器、无联网数据上报，保障绝对隐私。

## 测试验证

在配置完整 Xcode 环境的 Mac 上：

```sh
swift test
swift build -c release
```

测试集全面覆盖时长累加、超时追加、暂停、离开判定、会话切换、午夜跨日、JSON 序列化与故障恢复。
原有的宠物物理与核心功能测试完整保留在测试 Target 中。
GitHub Actions CI 会在每次提交时自动运行 macOS 单元测试与 Release 构建。

在缺少完整 XCTest 的轻量环境或 CommandLineTools 环境下，可以运行独立测试脚本：

```sh
./scripts/check_todo.sh
```

该脚本使用临时文件和模拟时钟运行，不会触碰您的真实待办数据。它作为 XCTest 测试套件的有益补充。

如需隔离调试 UI，可将环境变量 `TYPINGPET_TODO_TEST_PATH` 指定为临时 JSON 路径。
以参数 `--todo-preview --show-todos` 运行 Debug 构建，可跳过输入监控权限引导直接呼出待办列表。
正式 Release 构建会忽略这些测试参数，始终使用标准生产存储路径。
